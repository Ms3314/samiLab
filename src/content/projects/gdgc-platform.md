## What it is

The internal platform for the Google Developer Group chapter at MJCET. As Tech Captain I led more than 5 developers building it.

It includes the chapter's website and a LeetCode-style coding judge with its own judge worker, so members can solve problems on the platform. It runs behind sign-in at gdgcmjcet.in.

## The website

The public site is a React 19 app built with Vite, React Router, Tailwind CSS and Framer Motion, with Home, About and Hiring pages and a responsive navigation bar.

The front end, back end and judge worker each have their own repository, linked above.
