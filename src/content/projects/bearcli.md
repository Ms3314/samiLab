## What it is

BearCLI is a homemade AI coding agent for the terminal, wrapped around GPT-5.

## What it can do

- **Create applications.** Turn an idea into a project, from a small script to a scaffolded app.
- **Run Linux commands.** Navigate directories, manage files and run scripts without leaving the tool.
- **Two modes.** Switch between AI chat and Linux command mode.
- **Keep you company.** When the bugs get tough, Bear is friendly about it.

It was an early experiment in agentic behaviour: the agent suggests and takes the next step, instead of only answering.
